# 已知限制与验证边界

本仓库是早期项目源码整理，不是已经验收可直接收款的服务。

- **任务可靠性**：后台任务在 Web 进程内运行，没有持久化队列、重启恢复或统一取消协议。`backend/api/image.py` 的成功结算与 `reset_tasks` 之间需要并发状态约束，当前没有压力测试或崩溃恢复证明。
- **积分与事务**：入口条件 UPDATE 能约束可用积分；后台结算仍有读改写，并不能据此宣称跨进程强一致或 exactly-once。`backend/crud/image.py::create_image_log` 自行提交事务；`reset_active_tasks` 会释放额度，任务本身可能继续运行。
- **日消费上限与内容审核**：只有 `backend/crud/image.py::get_daily_total_points` 汇总函数，生成入口未调用；不存在已验证的全站消费熔断或内容审核服务。
- **接口权限与代理**：`/image/status/{id}`、图片下载、支付状态等接口需补充归属审查；`/image/proxy` 接收任意 URL，需在公网使用前限制目标和重定向以防 SSRF。未把这些接口描述为完备安全防护。
- **支付**：回调金额比较被注释，签名使用适配器原有 MD5 方式；缺配置时创建订单仍可能先落库。未连接真实商户、未付款，不应直接收款。
- **注册与验证**：手机注册没有真实短信验证；图形验证码的服务端校验、注册事务及账号枚举防护仍需专项验证。可以先用本地初始化管理员体验界面。
- **数据库**：本轮仅验证空白 SQLite；原 MySQL SQL 脚本与 ORM 字段不一致且含默认种子账号，整理时移除。部分 ORM String 字段未指定长度，MySQL 建表需另做迁移和验证。
- **上游兼容性**：`gpt-image-2` 和 JSON edits 格式是原源码约定，未在本轮调用任何真实生图服务。standard/hd/master 的价格和提示词不同，上游实际都发送 low，不能宣传真实质量差异。
- **依赖**：前端锁文件原样保留，本轮 npm audit 报告 18 项漏洞（1 low / 5 moderate / 12 high）；构建成功不代表依赖安全。生产前应逐项评估并回归升级。后端依赖未锁版本，安装结果可能随时间变化。
- **素材**：本次只从原仓库选用现有图，没有打开本机 App 或微信截图。删除了无法确认授权的人像和含二维码的图；保留素材经目视检查未发现个人联系信息。未取得可独立证明每张历史素材来源和权利的材料，MIT 只覆盖贡献者有权许可的代码，品牌和作品权利仍归原权利人。
- **未验收**：真实生图、COS 上传、SMTP、支付、浏览器完整交互与响应式视觉、PWA 真机安装、MySQL、并发与长期运行均未在本轮验证。没有部署。
